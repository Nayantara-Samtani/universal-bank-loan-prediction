# universal-bank-loan-prediction
Data mining project using Python and SAS Viya to analyze customer behavior and build decision tree models for loan prediction.

This was one of my first projects combining exploratory data analysis with predictive modeling. While the focus was primarily on learning the process of building and evaluating decision trees, it gave me practical experience working with customer data and applying predictive analytics concepts to a real-world business scenario.

This project was completed as part of my Data Mining & Predictive Analytics course. I worked with a customer dataset from Universal Bank to explore factors that may influence whether a customer accepts a personal loan. The project involved analyzing customer demographics and financial information, identifying patterns in the data, and comparing different decision tree models to better understand loan prediction.

I started by exploring the dataset in Python using histograms, box plots, and scatterplot matrices to better understand the distributions of the variables and how they related to one another. After completing the exploratory analysis, I used SAS Viya to build and compare several decision tree models using different splitting methods, including Gini, Entropy, Gain Ratio, and CHAID. Through this project, I gained experience with Python, Pandas, data visualization, descriptive analytics, decision trees, model evaluation, and SAS Viya.

The analysis showed that variables such as income, education, mortgage balances, and credit card spending were useful for understanding customer behavior and loan acceptance patterns. After comparing several decision tree approaches, I found that the Gini-based tree provided the best balance between prediction performance and simplicity. This project helped me better understand how predictive analytics can be used to support decision-making in the banking industry.
